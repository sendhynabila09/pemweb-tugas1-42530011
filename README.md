## Deskripsi

BelajarYuk merupakan konsep landing page katalog produk digital di bidang edukasi. Halaman ini dirancang untuk memperkenalkan fitur belajar, pilihan paket, perbandingan harga, testimoni, dan informasi kontak.

Landing page dibuat dengan pendekatan semantic HTML5 dan responsive design sehingga dapat digunakan pada berbagai ukuran layar, mulai dari perangkat ponsel hingga desktop.

## Teknologi

- HTML5 Semantik
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Chrome DevTools
- W3C Validator
- Lighthouse
- Git
- GitHub

## Fitur Halaman

- Header dan navigasi internal
- Skip link untuk membantu navigasi keyboard
- Hero section dengan tombol CTA
- Kartu fitur menggunakan CSS Grid
- Informasi keunggulan produk
- Kartu paket produk
- Tabel perbandingan paket
- Testimoni pengguna
- Aside sebagai informasi pelengkap
- Kontak dan footer
- Layout responsif untuk ponsel, tablet, dan desktop
- Semantic HTML5 untuk struktur halaman

## Pengujian

Pengujian dilakukan untuk memastikan struktur HTML, CSS, responsivitas, dan aksesibilitas halaman berjalan dengan baik.

### Responsive Testing

Pengujian dilakukan pada:

- **375 px** — tampilan ponsel
- **786 px** — tampilan tablet
- **1280 px** — tampilan desktop/laptop

Pengujian responsivitas dilakukan menggunakan Chrome DevTools.

### HTML Validation

Struktur HTML diperiksa menggunakan W3C HTML Validator.

### CSS Validation

Kode CSS diperiksa menggunakan W3C CSS Validator.

### Box Model

Pemeriksaan Box Model dilakukan menggunakan Chrome DevTools untuk memastikan penggunaan `box-sizing: border-box`, margin, padding, dan border berjalan dengan baik.

### Accessibility

Audit aksesibilitas dilakukan menggunakan Lighthouse.

**Hasil Accessibility: 95/100**

Hasil tersebut telah memenuhi target minimal **90** untuk accessibility.
